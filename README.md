# TYS Escalation Atlas

EDA website of **Team TYS** for the alert-escalation hackathon (financial-sector monitoring, Uzbekistan): how we explored the transaction histories behind 20,000 automated alerts, what separates escalated from dismissed alerts, and how those observations became the model.

**Live site:** https://hmunisbekk-droid.github.io/tys-escalation-eda/

The page is a single self-contained `index.html` (inline SVG charts computed from the training data; fonts from Google Fonts). Every figure and number on it is produced by the team's reproducible pipeline from the five competition files.

Data provenance: the competition data are synthetic and were transformed and localized for the hackathon; they contain no real customer or transaction records.
